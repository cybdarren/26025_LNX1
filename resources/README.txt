This directory contains compiled output from a bitbake session.
Two files are provided:
The .wic contains the image suitable for burning onto an SD-Card.
The .sh contains the sdk that matches the built image. it should be installed into /opt/mchp-lnx1-sdk

Also in this folder is the install_26025_lnx1.sh.
It is anticipated you will obtain this file either directly or by cloning this repo. Then place the script in the user root folder ~. Then run the script, it will install all of the requirements for the class.
